# Mini Code Compiler

A simple local coding platform with:
- Code editor with syntax highlighting and line numbers
- CodeMirror editor with auto-indent and bracket matching
- Save/load/reset support using browser storage
- Snippets for each language
- Dark/light theme, font size, font selection, and layout toggle
- Output console, copy output, clear console, and run history
- Multiple languages: JavaScript, Python, C, C++

## Setup

1. Open a terminal in the project folder.
2. Run `npm install`.
3. Start the app with `npm start`.
4. Open `http://localhost:3000` in your browser.

## Notes

- JavaScript runs with `node`.
- Python runs with `python`.
- C/C++ require `gcc`/`g++` available on PATH.
- This demo is intended for local use and does not provide production-grade sandboxing.
